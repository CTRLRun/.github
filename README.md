# .github

Organisation-wide defaults for [CTRLRun](https://github.com/CTRLRun).

| Path | What it does |
|---|---|
| `profile/README.md` | Renders at the top of [github.com/CTRLRun](https://github.com/CTRLRun) |
| `SECURITY.md` | Fallback security policy for repos without their own |
| `CODE_OF_CONDUCT.md` | Fallback code of conduct |
| `CONTRIBUTING.md` | Fallback contributing guide |

Health files here apply only to repositories that do not ship their own copy. `ctrlrun` ships all
of its own, so these serve future repositories.
